# Release review

When the user requests a release review, compare each release criterion against evidence from the conversation and project. A checked box records the user's claim; it is not proof that a check ran. Separate verified, unverified, and failed checks. Ask for missing evidence before describing an unverified item as passed.

Use `summarize_release_checklist` when asked to summarize a supplied checklist. Its result only summarizes that supplied input. It does not execute tests, inspect a repository, publish a release, or approve a deployment. Report the actual checks performed and their limits.
