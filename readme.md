# Official Latch plugins

[简体中文](readme.zh-CN.md) · [Contributing](CONTRIBUTING.md)

To install from this repository, clone it on the Mac running Latch. Open **Settings › Plugins › Add plugin…**, enter the checkout’s absolute path, and choose a plugin. Review its version and permissions before applying it. Public repositories can also be added by GitHub URL. [Plugin catalog](latch.catelog.json)

| Plugin | What it does |
| --- | --- |
| [Shift handoff](plugins/shift-handoff/) | Turns a conversation into handoff notes with completed work, open questions, and next steps. |
| [Release checklist panel](plugins/release-review/) | Lets you mark release criteria beside a conversation and send the checklist to your agent for review. |
| [Release check history](plugins/release-check/) | Runs release checks by project and keeps the results, evidence, and notes for each item. |
| [Context](plugins/context-insights/) | Compare request inputs and window usage by turn. Jump to a tool result or inspect a reported compaction. |
