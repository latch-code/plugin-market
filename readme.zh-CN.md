# Latch 官方插件

[English](readme.md) · [贡献指南](CONTRIBUTING.md)

| 插件 | 用途 |
| --- | --- |
| [交接清单](plugins/shift-handoff/) | 把对话整理成交接说明，列出已完成的工作、待确认的问题和下一步。 |
| [发布清单面板](plugins/release-review/) | 在会话侧栏勾选发布条件，把清单发给 Agent 核对。 |
| [发布检查记录](plugins/release-check/) | 按项目发起发布检查，留存每项检查的结果、证据和备注。 |
| [上下文](plugins/context-insights/) | 查看每次模型请求的组成、token 用量和工具调用，点选请求可跳到对应的对话回合。 |
